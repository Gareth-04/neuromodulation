Neuromodulation
A PHP web application for completing and managing a Neuromodulation Brief Pain Inventory (BPI) form.
-----------------
What I Have Built
-----------------
index.php
---------
This is the main Neuromodulation form.
It contains a Patient Details section with:
First name
Surname
Date of birth
Age

The age is automatically calculated from the patient's date of birth using jQuery.
The page also contains the Brief Pain Inventory (BPI) questions.

Question 1 has a score range of 0–100.
Questions 2–12 have a score range of 0–10.
The selected score is displayed next to each slider.
A Total Score is displayed at the bottom of the form.

The total score is calculated using questions 2–12 only. Question 1 is not included in the total.

Bootstrap is used for the layout and styling, and jQuery is used for the interactive calculations.
-----------
admin.php
-----------
The admin page displays the completed forms in a table.
The table contains:
Date of submission
First name
Surname
Age
Date of birth
Total score
Each row can be selected to open an individual form using its FormId.
The admin page uses PHP to connect to the database and retrieve the completed forms.
------------
Database
------------
Microsoft SQL Server is being used to store the completed forms.
The database is called:
Neuromodulation

The database contains a table called:
NeuromodulationForms

The table stores:
Form ID
First name
Surname
Date of birth
Questions 1–12
Total score
Date of submission
The FormId is automatically generated by SQL Server.
The submission date is also automatically generated by SQL Server.
------------
SQL Scripts
------------
Three SQL scripts have been created.
Script 1 – Database
The first script checks whether the Neuromodulation database exists.
If it does not exist, the database is created.

Script 2 – Table
The second script creates the NeuromodulationForms table.
It also contains validation rules for the question scores.

Question 1 must be between:

0–100

Questions 2–12 must be between:
0–10

The total score must be between:
0–110

Script 3 – Stored Procedures
The third script contains the stored procedures required to work with the forms.
The procedures are:

NeuromodulationForm_Create
NeuromodulationForm_GetAll
NeuromodulationForm_GetById
NeuromodulationForm_Update
NeuromodulationForm_Delete

These provide the CRUD functionality for the application.
CRUD means:

Create
Read
Update
Delete
The total score is calculated by SQL Server from questions 2–12 when a form is created or updated.
Database Connection
A Database.php file is being used to handle the connection between PHP and SQL Server.
It is located in:

src/Database.php

The PHP pages can use this connection to communicate with the SQL Server database and call the stored procedures.
